FrankenClaw

Withdrawn from public distribution.
⚠ As of August 17, 2026, FrankenClaw is no longer publicly available. We pulled the repository as a security precaution: a tool chassis that executes code on the machines it runs on deserves a smaller public footprint than we were giving it, and we chose caution over reach. Nothing was compromised — this is prevention, not response.

The project is not dead — it continues in private use and development. The GitHub repository, its install links, and the one-line installer on this site no longer work for the public, deliberately.

Already running FrankenClaw? Your local install keeps working — nothing phones home and nothing expires. It just won’t receive public updates. If you’re an existing user who needs help, or you have a serious use case, reach out via GitHub (@GuyMannDude) — open an issue on any public Project Sparks repo.

The rest of the product line is unaffected and remains open source.
