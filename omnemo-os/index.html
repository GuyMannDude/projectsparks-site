Omnemo OS

Omarchy, made easy, made for memory.

A taskbar. Plain-words buttons. A “?” guide to every icon. And Omnemo memory already set up, so the AI helpers on your computer remember you — and remember each other.

Two Ways To Get It

Just the memory, or the whole thing.

🧠
Just the memory
Already on Omarchy and happy with it? Install Omnemo on its own. Its guide shows you how to use it. Nothing about your desktop changes.
🖥️
The whole thing: Omnemo OS
Install Omarchy from its own installer, then run our one command. It sets up the friendlier desktop and Omnemo memory together. If Omnemo is already on your computer, it is left exactly as it is.
Install

Three steps. Password only for the snapshot.

This preview needs Omarchy's 4.5 test version (the release candidate). It never asks for your password, except Omarchy's own snapshot step.

  1. Take a snapshot so you can undo. Open a Terminal (Super + Enter) and type omarchy snapshot create. It asks for your password.
  2. Switch to the test version. Omarchy menu → Update → Channel → RC, then Update → Omarchy.
  3. Paste the three lines below into the Terminal.
$ git clone https://github.com/GuyMannDude/omnemo-os
$ cd omnemo-os
$ bin/omnemo-os install --allow-rc

--allow-rc is only needed while 4.5 is a test version. The memory part downloads a few hundred MB, so it needs the internet and a couple of minutes. Offline? The desktop still installs, and bin/omnemo-os repair adds the memory later.

When it finishes, start a new session of your AI helper (Claude, Codex, …) and it shares one memory with the others.

Afterwards, from the omnemo-os folder

$ bin/omnemo-os status     # what's installed (memory included); flags anything an update reset
$ bin/omnemo-os repair     # puts it back
$ bin/omnemo-os uninstall  # everything back exactly as it was, except your memories
Your Memories Are Yours

Uninstall never touches them.

Uninstall removes the memory program it installed but never your memories. They stay in ~/.local/share/omnemo, and uninstall tells you where. Install again later and they are picked up where you left off.

To delete them yourself, copy that folder somewhere safe, then delete it. A keep-or-start-fresh question is coming in 0.9.2.

Share Your Ideas

You don't need to be a programmer to help.

Omnemo OS is brand new, and it's being shaped by the people who use it. If something is confusing, annoying, or missing, we want to hear it.

🗣️
Plain words are perfect
Tell us what you were trying to do and what got in the way. “I couldn't find how to change the wallpaper” is a perfect report.
📱
A phone photo is fine
No logs needed. A picture of your screen tells us most of what we need.
💡
Ideas welcome
A button you wish was on the bar, an app you'd like in Favorites, anything.

Problems or confusion: on the GitHub page click Issues → New issue → “Something went wrong (or confused me)”. Ideas: click Discussions → Ideas. You'll need a free GitHub account, or ask your AI assistant to write it up for you and paste it there. Every message gets read.

If something breaks badly, bin/omnemo-os uninstall puts your desktop back exactly the way Omarchy had it.
