Install

Ask your agent to do it.

The fastest way: let the AI you already have install it for you.

# 1. if you haven't, pick an agent:
$ omarchy default agent claude

# 2. open it:
$ omarchy agent

# 3. say:
Install Omnemo — follow INSTALL.md.

Is your agent Codex or OpenCode? Do INSTALL.md step 0 first — there's one thing to set up before you start. (For Codex, type codex instead of claude above.)

After that, your agent does the rest. Prefer to do it by hand? The install guide walks every step, and every step ends with a check.

Prove It

Don't take our word for it.

A memory is safe the instant the save comes back. A crashing agent loses nothing. Run this:

$ python3 examples/crash_demo.py

It saves a memory, kills the memory server the moment the save is confirmed — no shutdown, no tidy-up — then starts fresh and finds the memory again.

Save in one agent, recall in another

The whole promise in two commands, on a box with two signed-in agents:

# Ask Claude Code (Anthropic) to remember something
claude -p 'Use the omnemo save tool to store this memory: the electronics
repair shop favorite song was "Everything'\''s Broken" by Bob Dylan' \
  --allowedTools "mcp__omnemo__save"

# Ask Codex (OpenAI) — a different vendor's harness, fresh process
codex exec 'Using only the omnemo MCP recall tool: what was the favorite
song at the electronics repair shop?'

Run live on the reference box:

Honest Numbers

What to expect on a low-spec box

Measured 2026-10-30 on a 2016 laptop: Intel i3-6100U (2 cores / 4 threads), 3.7 GB RAM, Omarchy 4.5.0rc2 (rc channel), Omnemo 0.2.1.dev3, timed over the real MCP stdio path.

WhatNumber
Cold start (spawn omnemo serve → first recall answered)2.6 s
Warm recall, 20 calls (4 memories)p50 167 ms, p95 202 ms
Warm recall, 20 calls (1,000 memories)p50 136 ms, p95 148 ms
Savep50 79 ms, p95 139 ms
Server memory (RSS), warm~330 MB (337 MB at 1,000 memories)
Store on disk32 KB at 4 · 236 KB at 100 · 2.1 MB at 1,000 memories
One-shot CLI omnemo recall (loads the model each time)1.6–1.9 s

Most of the memory and the cold start is the local embedding model (BAAI/bge-small-en-v1.5). Each harness runs its own server, so budget ~330 MB per open harness on a 4 GB machine. The cold start was measured with the model already in the OS file cache; the first run after a reboot is slower.
