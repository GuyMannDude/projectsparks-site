The Product Line

Products

Three open-source products that give your AI memory. Adopt any one — they don't lock each other in.

Mnemo Cortex
Cognitive coprocessor with active memory. Semantic recall, cross-agent dreaming, workspace document search, Developer's Passport. Runs natively on Linux, Windows, and macOS (beta). Open source and yours to modify.
Product page GitHub
Omnemo
Memory for Omarchy. One shared memory store for every agent harness on the box — save in one, recall in any. Proven live across Claude Code and Codex. Built from Omarchy's own extension points, so it survives every omarchy update.
Product page GitHub
Omnemo OS
An easy-to-use desktop with memory built in. Our edition of Omarchy — v0.9 public preview, out now.
Product page GitHub
Support Utilities

The helpers behind the products.

Used by Mnemo Cortex and the fleet behind Project Sparks. Free and open source, if you need the same thing.

Disco-Bus
Push-based agent-to-agent message mesh with full delivery confirmation. SQLite-backed dispatcher, per-agent HTTP listeners, optional Discord mirror. Sub-second delivery, ~1000 lines of code.
Product page GitHub
Cortex Stick
Sneakernet for AI memory. A USB stick that couriers your agents' memory between two desks — no cloud, no VPN, no account. AES-256 encryption, yank-proof syncs. Ships inside Mnemo Cortex.
