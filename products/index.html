Open-source AI agent infrastructure. Adopt any single piece — they don't lock each other in.

Mnemo Cortex
Cognitive coprocessor with active memory. Semantic recall, cross-agent dreaming, auto-compiled wiki, Developer's Passport. Runs natively on Linux, Windows, and macOS (beta).
Product page GitHub
Disco-Bus
Push-based agent-to-agent message mesh with full delivery confirmation. SQLite-backed dispatcher, per-agent HTTP listeners, optional Discord mirror. Sub-second delivery, ~1000 lines of code.
Product page GitHub
FrankenClaw
An MCP tool chassis — build your own agent tools in five minutes. Drop a Python file in tools/, flip it on, done. Tools are off by default: zero tokens until enabled.
Product page GitHub
Cortex Stick
Sneakernet for AI memory. A USB stick that couriers your agents' memory between two desks — no cloud, no VPN, no account. AES-256 encryption, yank-proof syncs. Ships inside Mnemo Cortex.
