Install Mnemo Cortex

Written so a person or an AI assistant can follow it. If an AI sent you here: do the steps below on the user's machine, then connect Mnemo to the AI they use, then set it up for whatever they asked for.

What you need

A computer running Linux, Windows (native, no WSL) or macOS (beta), with Python 3.11 or newer and git. For the local brain, Ollama is recommended; any API provider works too.

Five steps

  1. Get the code. git clone https://github.com/GuyMannDude/mnemo-cortex.git && cd mnemo-cortex
  2. Make a home for it. python -m venv .venv && source .venv/bin/activate (on Windows: .venv\Scripts\activate)
  3. Install it. pip install -e .
  4. Answer the setup questions. mnemo-cortex init picks your models and writes the config.
  5. Start it. mnemo-cortex start brings the memory server up on port 50001.
$ git clone https://github.com/GuyMannDude/mnemo-cortex.git && cd mnemo-cortex
$ python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
$ pip install -e .
$ mnemo-cortex init    # config wizard: pick your models
$ mnemo-cortex start   # server up on port 50001

Then connect it to the AI you use

Each integration is one folder in the repo with its own README. Pick the one that matches:

  • Claude Code: two hook scripts, zero config.
  • Claude Desktop: a drop-in MCP bridge.
  • Hermes Agent: one-shot installer.
  • OpenClaw: MCP v2, cross-agent sharing off by default.
  • Any local LLM: LM Studio, AnythingLLM, Open WebUI, llama.cpp, Ollama, LobeChat, Jan.

The full, always-current guide is INSTALL.md in the repo. If this page and INSTALL.md ever disagree, INSTALL.md wins.

"Set it up for my shop"

Once Mnemo is running and connected, there is nothing else to configure. Just start talking about the thing: the shop, the band, the recipes. Mnemo saves what matters and brings it back next time. For a ready-made starting point, the mnemo-plan template gives your AI a folder of plain-text project notes to read at the start of every session.

Stuck? Ask on GitHub Discussions. Plain words are perfect.
